# Задача 5. UI/UX — русификация и понятные этапы

## Цель
Понятный русский интерфейс, чистая навигация, разделение админ/пользователь.

## Что сделать
1. Перевести подписи меню/кнопок на русский (все шаблоны).
2. Сделать отдельный вход для админа (простая форма + пароль в .env).
3. Пользовательский режим — без паролей, только подготовленные закупки.
4. Добавить «Загрузить ещё 10» в user‑списке (limit/offset).

## Проверка
- Вся навигация и этапы на русском.
- Пользователь видит только `url_ready`.
- Админ готовит Stage 1–3.

- `src/web/templates/*.html`
- `src/api/routes.py`
- `src/web/static/css/style.css`
