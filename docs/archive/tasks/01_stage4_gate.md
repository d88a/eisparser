# Задача 1. Gate для Stage 4 (обязательная проверка статуса)

## Цель
Запуск Stage 4 только для подготовленных закупок со статусом `url_ready`.

## Что сделать
1. В `POST /api/user/run_stage4` добавить фильтрацию по `z.status == "url_ready"`.
2. Если в выборке есть закупки без `url_ready`, вернуть предупреждение с перечислением reg_number.

## Проверка
- Если есть закупка только с `two_gis_url`, но статус `ai_ready`, Stage 4 не запускается.
- Если все выбранные закупки `url_ready`, Stage 4 запускается.
