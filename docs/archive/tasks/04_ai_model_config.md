# Задача 4. Конфигурация AI‑модели (Stage 2 блокер)

## Цель
Обеспечить работающий Stage 2 после выбора новой модели.

## Что сделать
1. Обновить `.env` (модель/ключ) после вашего выбора.
2. Обновить документацию: где хранится ключ, как задать модель.
3. Проверить один успешный запуск Stage 2 на тестовой закупке.

## Проверка
- Ошибка 404 по модели исчезает.
- Stage 2 возвращает результат ИИ.
