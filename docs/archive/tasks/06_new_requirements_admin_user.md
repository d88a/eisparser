# Новое ТЗ: два входа, чистый код, без дублирования

## Цель
Сделать два входа (админ/пользователь), скрыть Stage 1–2 от пользователя, привести код в порядок и исправить текущие ошибки.

## Ключевой сценарий
- Админ входит по паролю и видит все 4 этапа (Stage 1–4).
- Пользователь входит без пароля и видит только список закупок, одобренных админом.
- Пользователь видит 10 закупок за раз + кнопку «Показать ещё».
- Раздел для пользователя называется **«Закупки с ЕИС»**, а не «Готовые закупки».

---

# Задача A. Два входа (админ/пользователь)

## Что сделать
1. Добавить страницу входа для админа `/admin/login`.
2. Пароль хранится в `.env` (например `ADMIN_PASSWORD`).
3. После входа — доступ ко всем этапам Stage 1–4.
4. Пользовательский вход без пароля (можно просто отдельный маршрут `/user` или кнопка «Войти как пользователь»).

## Ограничения
- Без сложной авторизации. Минимум: cookie/sessions.

---

# Задача B. Пользовательский режим

## Что пользователь видит
- Только **закупки, одобренные админом** (например `status == url_ready`).
- Список по 10 штук + кнопка «Показать ещё».
- Название раздела: **«Закупки с ЕИС»**.

## Поведение
- Пользователь выбирает закупки и запускает Stage 4 вручную.
- Stage 1 и Stage 2 **не видны** пользователю.

---

# Задача C. Админка

## Что админ видит
- Все этапы Stage 1–4.
- Возможность запуска Stage 4 из админки тоже должна быть.

---

# Задача D. Чистый код и исправление ошибок

## Что исправить
1. Убрать дублирование API кода (один источник в `src/api/routes.py`).
2. Архивный файл оставить только как архив (если нужен) или удалить.
3. Исправить все старые ошибки (`db_service`, `get_result`, gate Stage 4).

---

# Артефакты
1. Код изменений.
2. Список затронутых файлов.
3. Краткий отчёт (что сделано и как проверить).

---

# Критерии приёмки
- Два входа: админ с паролем, пользователь без пароля.
- Пользователь видит только закупки из БД, одобренные админом (url_ready).
- Пользовательский список называется «Закупки с ЕИС».
- Лимит 10 + кнопка «Показать ещё».
- Админ видит Stage 1–4.
- Код без дублирования, ошибки исправлены.
