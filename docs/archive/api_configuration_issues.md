# Проблемы с конфигурацией API в EIS Parser

## Обзор
На основе лога выполнения обнаружена ошибка, связанная с конфигурацией API Gemini, которая не была учтена в документации проекта.

## Ошибка в логе

```
2026-01-30 13:10:04 | ERROR    | eisparser.AIProcessorService | Ошибка API: 404, {"error":{"message":"No endpoints found for google/gemini-2.0-flash-exp:free.","code":404},"user_id":"user_2w4PMIpC3jcfO0MxczcuQafBAEc"}
```

## Анализ проблемы

### 1. Проблема с настройками API
**Тип ошибки**: 404 Not Found для эндпоинта `google/gemini-2.0-flash-exp:free`

**Возможные причины**:
- Устаревшее имя модели в конфигурации
- Неправильная настройка API-ключа
- Изменение в API Google Gemini (например, экспериментальная модель больше не поддерживается)

### 2. Недостаточная обработка ошибок API
**Файл**: `src/services/ai_processor_service.py`
**Проблема**: Ошибка возникает при попытке обращения к API Gemini, но система не предоставляет пользователю ясного способа исправить ситуацию.

### 3. Зависимость от внешнего API
**Проблема**: Приложение зависит от внешнего API, который может изменяться или быть недоступным, что влияет на функциональность системы.

## Рекомендации

1. **Обновить конфигурацию API**:
   - Проверить актуальное имя модели Gemini
   - Обновить настройки в `.env` файле или конфигурации
   - Рассмотреть использование стабильной версии модели вместо экспериментальной

2. **Улучшить обработку ошибок API**:
   - Добавить более информативные сообщения об ошибках
   - Реализовать fallback-механизмы при недоступности API
   - Добавить проверку доступности API при запуске приложения

3. **Добавить документацию по настройке API**:
   - Описать процесс получения и настройки API-ключа
   - Указать поддерживаемые модели и их особенности

## Влияние на проект

Эта ошибка блокирует функциональность Stage 2 (ИИ-обработка), которая является критической частью проекта. Без корректной настройки API Gemini система не может выполнять основную задачу - извлекать параметры объектов недвижимости из текстов закупок.

## Связь с этапами 1-2

Ошибка напрямую влияет на Stage 2, который:
- Обрабатывает тексты закупок через ИИ
- Извлекает параметры (город, площадь, комнаты и т.д.)
- Формирует основу для последующих этапов (Stage 3 и Stage 4)

Без корректной работы Stage 2, пользователь не может получить результаты ИИ-анализа, что делает невозможным дальнейшую обработку закупок.
