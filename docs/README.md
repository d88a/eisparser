# Документация проекта EIS Parser (актуальная)

## Основные документы
- `docs/PROJECT.md` — архитектура, запуск, развёртывание на новом ПК.
- `docs/INTERN_TASKS.md` — актуальное техническое задание стажёру.

## Как работать в админке
1. Этап 1: откройте вкладку «Загрузка новых», выберите количество закупок, нажмите «Показать новые закупки», отметьте нужные и нажмите «Скачать и сохранить выбранные».
2. Этап 2: откройте «ИИ-анализ», выделите закупки и запустите обработку. Проверьте поля справа, при необходимости исправьте значения.
3. Этап 3: сформируйте и сохраните ссылку 2ГИС для каждой закупки, которая пойдёт в сбор объявлений.
4. Этап 4: откройте «Сбор объявлений», выберите закупки и запустите сбор. Источники в карточке объявления показаны строкой «Ссылки: 2ГИС | Домклик | Циан | Avito».

## Важно по Этапу 4
- Каноническая ссылка процесса берется только из Stage 3 (`zakupki.two_gis_url`).
- Ссылки карточек объявлений (`.../ad/...`) и внешние источники показываются только как вспомогательные данные и не подменяют ссылку Stage 3.
- Если канонической ссылки нет, в интерфейсе Stage 4 выводится `Ссылки нет (Этап 3)`.

## Архив
- Исторические материалы вынесены в `docs/archive/` и не считаются источником актуальных требований.
